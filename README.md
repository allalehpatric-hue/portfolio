# Portfolio — Allaleh Ismael Aden

Site statique (HTML/CSS/JS, aucune installation nécessaire).

## Mettre en ligne sur GitHub Pages
1. Créez un dépôt public nommé `allalehpatric-hue.github.io` (ou un autre nom).
2. Envoyez-y tout le contenu de ce dossier (`index.html`, `img/`, `cv/`).
3. Dans le dépôt : Settings → Pages → Source : branche `main`, dossier `/ (root)`.
4. Le site sera en ligne à l'adresse indiquée par GitHub après une à deux minutes.

## Modifier
- Textes : directement dans `index.html`.
- CV : remplacez `cv/CV_Allaleh_Ismael_Aden.pdf` par votre version à jour (même nom de fichier).
- Images : dans `img/` (format .webp ; la version `-mini` sert de miniature).
